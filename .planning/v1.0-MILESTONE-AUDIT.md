### Integration Findings

**INT-01 (MEDIUM) — Stale delegation messages after Diataxis integration**

The Editor agent now runs four sequential passes (Terminology → Diataxis Type Integrity → Humanizer → Cross-References) after commit `b126e44`. All three orchestrator skills still instruct: "run all **three** passes: terminology, humanizer, and cross-references." The Diataxis Type Integrity pass is unnamed and may be skipped.

Affects: INTG-01, INTG-02, INTG-03, EDIT-04
Fix: Update delegation messages in write/review/edit skills to name four passes.

**INT-02 (HIGH) — Setup Q&A missing domain_context and discovery_story collection**

Phase 4 added `domain_context` and `discovery_story` fields to config-template.yaml for richer Persona scenario generation. The setup Q&A flow does not collect these values — they default to empty strings. Persona gracefully degrades (infers from audience name) but loses specificity.

Affects: SETUP-01, PERS-01, PERS-02
Fix: Extend setup SKILL.md Step 2a with two optional questions.
